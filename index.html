About HTML

What is HTML?

HTML provides the basic structure of a webpage. It tells the browser what content should appear on the page.

For example: <h1> creates a heading and <p> creates a paragraph.

HTML Document Structure

<!DOCTYPE html>

<html>

    <head>
        <title>My Website</title>
    </head>

    <body>

        <h1>Hello World</h1>

    </body>

</html>
